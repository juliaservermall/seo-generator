# 📖 Инструкция по развёртыванию генератора SEO-описаний

## Предварительные требования

Убедитесь, что у вас установлены:

1. **Node.js** (версия 18 или выше)
   - Проверка: откройте терминал/PowerShell и выполните:
     ```
     node --version
     ```
   - Если не установлен — скачайте с https://nodejs.org (версия LTS, например 20.x)
   - После установки **перезагрузитесь**

2. **npm** (обычно идёт вместе с Node.js)
   - Проверка:
     ```
     npm --version
     ```

3. **OpenAI API ключ**
   - Откройте https://platform.openai.com/account/api-keys
   - Авторизуйтесь в своём OpenAI аккаунте
   - Нажмите "Create new secret key"
   - Скопируйте ключ (вы больше его не сможете увидеть)

---

## Шаг 1: Распаковка архива

1. Скачайте файл `seo-generator.zip`
2. Распакуйте его в удобную папку:
   - **Windows**: правый клик → "Извлечь все"
   - **Mac/Linux**: двойной клик или команда `unzip seo-generator.zip`

Должна появиться папка `seo-generator` со следующей структурой:
```
seo-generator/
├── lib/          (библиотеки логики)
├── pages/        (веб-страницы и API)
├── styles/       (CSS)
├── package.json
├── .env.example
└── README.md
```

---

## Шаг 2: Открытие терминала в папке проекта

**Windows:**
1. Откройте папку `seo-generator`
2. Нажмите в адресной строке и напечатайте `cmd`, затем Enter
3. Откроется чёрное окно терминала (PowerShell или CMD)

**Mac:**
1. Откройте Finder, перейдите в папку `seo-generator`
2. Нажмите Cmd+Space, введите "Terminal", Enter
3. Перетащите папку `seo-generator` в окно терминала
4. Нажмите Enter

**Linux:**
1. Откройте файловый менеджер, перейдите в `seo-generator`
2. Правый клик → "Открыть в терминале"

Результат: в терминале вы видите путь типа `C:\Users\...\seo-generator>` или `/Users/.../seo-generator$`

---

## Шаг 3: Установка зависимостей

В открытом терминале выполните:

```bash
npm install
```

Процесс займёт 2–5 минут. Вы увидите логи установки:
```
added 107 packages in 12s
```

Если при этом видите ошибки вроде "error" в красном — **не пугайтесь**, часто это warnings, не критичные. Если процесс завершился с "added X packages" — всё ок.

---

## Шаг 4: Создание файла `.env`

1. В папке `seo-generator` найдите файл `.env.example`

2. Создайте копию и назовите её `.env`:
   - **Windows**: правый клик на `.env.example` → "Копировать", затем правый клик в пустом месте → "Вставить"
   - **Mac/Linux**: в терминале выполните:
     ```bash
     cp .env.example .env
     ```

3. Откройте файл `.env` любым текстовым редактором (Notepad, VS Code, TextEdit и т.д.)

4. Найдите строку:
   ```
   OPENAI_API_KEY=sk-replace-me
   ```

5. Замените `sk-replace-me` на ваш **реальный OpenAI API ключ**, который вы скопировали на этапе "Предварительные требования":
   ```
   OPENAI_API_KEY=sk-proj-abcd1234...
   ```

6. **Важно**: не окружайте ключ кавычками, просто вставьте как есть

7. Сохраните файл (Ctrl+S или Cmd+S)

**Пример правильного `.env`:**
```
OPENAI_API_KEY=sk-proj-aBcDeFgHiJkLmNoPqRsTuVwXyZ1234567890
```

## Использование приложения

### Этап 1: Загрузка файла

1. На странице нажмите на кнопку "Выбрать файл"
2. Выберите ваш CSV или XLSX файл (макс. 50 МБ)
3. Нажмите "Загрузить"

Приложение:
- Проверит наличие обязательных колонок (наименование, раздел, описание)
- Определит все доступные колонки
- Покажет список и количество строк

Если видите красное сообщение об ошибке — значит в файле отсутствует одна из обязательных колонок. Проверьте, что:
- Есть колонка с названием типа "Наименование" или "Наименование элемента"
- Есть колонка, в названии которой есть слово "раздел" (например "Название раздела")
- Есть колонка, в названии которой есть слово "описание" (например "Детальное описание")

### Этап 2: Выбор колонок

1. В разделе **"Колонки для контекста"** отметьте чекбоксами, какие колонки использовать для генерации описания
   - Наименование и раздел уже отмечены (они обязательны)
   - Добавьте другие колонки, которые могут помочь (характеристики, спецификации и т.д.)
   - Кнопка "Выбрать все" включит все доступные
   - Кнопка "Только обязательные" оставит только наименование и раздел

2. В разделе **"Колонка для записи"** выберите из выпадающего списка, в какую колонку писать результат:
   - Доступны только колонки, в названии которых есть "описание"
   - Например: "Детальное описание", "Описание для анонса"

### Этап 3: Настройки

1. **Модель** — выберите модель OpenAI (по умолчанию `gpt-5.4-nano`, самая быстрая)

2. **Лимит строк** — опционально ограничьте количество строк для быстрого теста
   - Оставьте пусто, чтобы обработать все строки

3. **Генерировать HTML** — отметьте, если хотите результат в виде HTML-разметки
   - С галочкой: будет `<p>текст</p>`, `<ul><li>` и т.д.
   - Без галочки: обычный текст с переносами строк

4. **Пропускать заполненные** — отметьте, чтобы не перезаписывать уже заполненные ячейки

### Этап 4: Запуск генерации

1. Нажмите кнопку **"Запустить генерацию"**

2. Вы увидите:
   - Прогресс-бар (сколько строк обработано)
   - Счётчики: успешно, пропущено, ошибки
   - **Лог внизу** — в реальном времени видны результаты для каждой строки

3. Генерация может занять время в зависимости от:
   - Количества строк
   - Размера выбранных данных
   - Загрузки OpenAI API
   - **Примерно: 1–2 секунды на одну строку**

4. Если нужно остановить — нажмите кнопку **"Остановить"**

### Этап 5: Скачивание результата

1. После завершения генерации нажмите **"Скачать результат"**

2. Файл скачается в вашу папку Downloads с именем типа:
   ```
   Пример_файла_with_descriptions.csv
   ```

3. **Важно**: файл сохранится в **исходном формате**:
   - CSV остаётся CSV (с тем же разделителем `;` и BOM)
   - XLSX остаётся XLSX (все остальные колонки и форматирование сохранены)

## Частые проблемы и решения

### ❌ Ошибка: "OPENAI_API_KEY не задан"
**Причина**: в файле `.env` забыли вставить ключ или вставили неправильно

**Решение**:
1. Откройте файл `.env` в текстовом редакторе
2. Проверьте, что строка выглядит так:
   ```
   OPENAI_API_KEY=sk-proj-...ваш-реальный-ключ...
   ```
3. Сохраните файл
4. В терминале нажмите Ctrl+C (остановить сервер)
5. Выполните `npm run dev` заново

### ❌ Ошибка: "Не удалось загрузить файл"
**Причина**: проблема с форматом CSV/XLSX

**Решение**:
- Проверьте, что файл действительно CSV или XLSX (откройте Excel и пересохраните)
- Убедитесь, что размер файла < 50 МБ
- Попробуйте загрузить пример `Пример_файла.csv` из комплекта — он точно работает

### ❌ Ошибка: "Обязательные колонки не найдены"
**Причина**: в файле нет нужных колонок

**Решение**:
- Откройте ваш файл в Excel
- Проверьте, что есть колонка с названием типа:
  - **Наименование**, или
  - **Наименование элемента**, или
  - **Наименование элементов**
- Проверьте, что есть колонка, содержащая слово **"раздел"** (любой регистр)
- Проверьте, что есть колонка, содержащая слово **"описание"** или **"описания"**

Если колонок нет — добавьте их в Excel и перезагрузите.

### ❌ Ошибка: "HTTP 401" при генерации
**Причина**: неверный или истёкший OpenAI API ключ

**Решение**:
1. Проверьте ключ на https://platform.openai.com/account/api-keys
2. Убедитесь, что у аккаунта есть баланс (paid account или free trial ещё активен)
3. Скопируйте новый ключ и обновите `.env`
4. Перезагрузите приложение в браузере (F5)

### ❌ Ошибка: "Таймаут при загрузке URL"
**Причина**: приложение пыталось загрузить страницу по ссылке из выбранной колонки, но ссылка недоступна

**Решение**: это не критично, генерация продолжится без контекста с той ссылки. Если хотите избежать — не выбирайте колонки с URL в "Колонки для контекста".

### ❌ Генерация очень медленная или ничего не происходит
**Причина**: сервер OpenAI перегружен или соединение нестабильно

**Решение**:
- Подождите пару минут
- Если всё равно не работает — нажмите "Остановить" и запустите генерацию заново
- Или попробуйте выбрать другую модель (например `gpt-5.4-mini` или `gpt-5.4`)

## Остановка приложения

Когда закончили работу:

1. В терминале нажмите **Ctrl+C** (Windows/Mac/Linux)

2. Вы увидит сообщение типа:
   ```
   Gracefully shutting down...
   ```

3. Приложение остановится

Чтобы запустить снова — просто выполните `npm run dev` в той же папке.

## Продвинутые настройки (опционально)

Если хотите настроить дополнительно — отредактируйте файл `.env`:

```bash
# Таймаут загрузки внешних URL (в миллисекундах)
URL_FETCH_TIMEOUT_MS=10000

# Максимальная длина текста, извлечённого со страницы (символы)
URL_TEXT_LIMIT=8000

# Максимальный размер загружаемого файла (МБ)
MAX_UPLOAD_MB=50

# Если используете прокси или локальный OpenAI-совместимый API:
# OPENAI_BASE_URL=http://localhost:8000/v1
```

## Где найти логи и ошибки

Если что-то не работает, посмотрите:

1. **В браузере**: F12 → вкладка "Console" — там красные ошибки

2. **В терминале**: когда сервер запущен (`npm run dev`), все запросы и ошибки видны в терминале

3. **На странице приложения**: в разделе "Генерация" внизу есть лог, где видны результаты для каждой строки

## Развёртывание на боевом сервере (опционально)

Если хотите запустить не на локальной машине, а на сервере или облаке:

### Вариант 1: Vercel (самый простой)
1. Создайте аккаунт на https://vercel.com
2. Подключите свой GitHub (или загрузите файлы напрямую)
3. При развёртывании добавьте переменную окружения `OPENAI_API_KEY`
4. Нажмите Deploy

### Вариант 2: Production build на своём сервере
```bash
npm run build
npm run start
```

Приложение запустится на `http://localhost:3000` в production-режиме (быстрее и стабильнее).
